# Prompt Engineering Learning

A beginner-friendly learning repository covering **Basic Prompt Engineering, Advanced Prompt Engineering, and Business Prompt Engineering**.

This repository is useful for students who want to understand prompt engineering in simple language and prepare for exams, assignments, and practical business applications.

## 📚 Topics Covered

### 1. Basic Prompt Engineering

Learn the fundamentals of creating clear and useful prompts.

Topics include:

* What is Prompt Engineering?
* What is a Prompt?
* Importance of clear prompts
* RCTF Framework

  * Role
  * Context
  * Task
  * Format
* Zero-Shot Prompting
* Few-Shot Prompting
* Marketing, HR, Finance, and Operations examples
* Prompt Improvement Cycle
* AI output review
* Sensitive information and AI tools
* Prompt Portfolio

A good basic prompt can be remembered as:

**Role + Context + Task + Format (RCTF)**

## 2. Advanced Prompt Engineering

Topics include:

* AI Self-Critique

* Reducing hallucination risks
* Facts vs Assumptions vs Recommendations
* Source Verification
* Prompt Quality Checklist
* Human Review

A stronger prompt can be remembered as:

**Role + Context + Task + Constraints + Format**

The Business Prompt Framework is:

**Role + Context + Task + Constraints + Format + Check**

## 🔄 Business Prompting Process

```text
Business Problem
       ↓
Required Information
       ↓
AI Task
       ↓
Prompt
       ↓
AI Output
       ↓
Human Review
       ↓
Business Decision
```

## 🛡️ Important Principles

* Write clear and specific prompts.
* Give AI enough context.
* Use constraints when necessary.
* Ask for structured output.
* Break complex tasks into smaller prompts when useful.
* Improve prompts through iteration.
* Do not blindly trust AI-generated information.
* Verify important facts, calculations, and sources.
* Separate facts, assumptions, and recommendations.
* Keep sensitive and confidential information out of unapproved AI tools.
* Human review is important.
* AI should support important business decisions, not replace human responsibility.
